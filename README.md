# JARVIS BD 🇧🇩

তোমার ফোনের জন্য একটা **সম্পূর্ণ কার্যকর বাংলা ভয়েস AI অ্যাসিস্ট্যান্ট** — কথা শোনে, বোঝে, টুল চালায়, আর উত্তর **বাংলায় গলায়** বলে।

> PWA (Progressive Web App) — মোবাইল ব্রাউজার থেকে **Add to Home Screen** দিলে নেটিভ অ্যাপের মতো আইকন + ফুলস্ক্রিন চলবে, ইন্টারনেট ছাড়াও খুলবে।

---

## ✨ যা যা পারে

| ক্ষমতা | বর্ণনা |
|---|---|
| 🎙 **বাংলায় কথা বলা** | মাইকে বলো → Web Speech API দিয়ে বাংলা টেক্সট → AI → উত্তর বাংলায় শোনাবে |
| 🗣 **Wake word** | “**জার্ভিস**” বলেই ডাকতে পারো — হাত দেওয়ার দরকার নেই |
| 🧠 **AI ব্রেইন** | Gemini / OpenRouter / Groq / Custom (Ollama) — যেকোনোটা |
| 🛠 **টুল ব্যবহার** | সময়, হিসাব, আবহাওয়া, ওয়েব সার্চ, নোট, টাস্ক, রিমাইন্ডার, ভাইব্রেশন, ব্যাটারি |
| ⏰ **রিমাইন্ডার** | “১০ মিনিট পর চা খাওয়ার কথা মনে করিয়ো” → সময়মতো নোটিফিকেশন + গলায় বলে |
| 🧾 **নোট / টাস্ক** | সব ফোনেই (localStorage) সেভ, সার্ভারে কিছু যায় না |
| 🌐 **লাইভ তথ্য** | আবহাওয়া (Open-Meteo, key লাগে না) + উইকিপিডিয়া/ DuckDuckGo সার্চ + OpenRouter `:online` মডেল |
| 📴 **অফলাইন** | সার্ভিস ওয়ার্কার — একবার লোড হলে ইন্টারনেট ছাড়াও অ্যাপ খুলবে |
| 🔐 **প্রাইভেসি** | API key শুধু তোমার ফোনের localStorage-এ থাকে |

## 🚀 ১০ সেকেন্ডে শুরু

### ধাপ ১ — খোলো
মোবাইল বা ডেস্কটপের **Chrome/Edge** ব্রাউজারে অ্যাপটি খোলো।

> ⚠️ **Safari/iOS:** ভয়েস ইনপুট সীমিত। Android-এ Chrome ব্যবহার করো — সবচেয়ে ভালো কাজ করে।

### ধাপ ২ — ফ্রি API key (২ মিনিট)
উপরের ডানদিকের ⚙ **সেটিংস** → প্রোভাইডার বেছে নাও:

**সবচেয়ে সহজ — Google Gemini (ফ্রি):**
1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → গুগল অ্যাকাউন্ট দিয়ে লগইন
2. **Create API key** → কপি
3. অ্যাপে → প্রোভাইডার `Google Gemini` → key পেস্ট → **সেভ ও টেস্ট করো** ✅

> ⚠️ **মডেল নিয়ে বিভ্রান্তি:** Gemini-এর মডেল নাম প্রতি কয়েক মাসে বদলায়। ২০২৬ সালের সেপ্টেম্বর অনুযায়ী চলতি মডেল: `gemini-3.8-flash` (ডিফল্ট), `gemini-3.7-flash`, `gemini-3.6-flash`, `gemini-3.5-flash`।
> `gemini-2.5-flash`-এর মতো পুরনো নাম **নতুন ইউজারদের জন্য বন্ধ** — এরর এলে ⟳ চেপে মডেল লিস্ট রিফ্রেশ করো, অ্যাপ নিজেই সেরা মডেল বেছে নেবে।
> অ্যাপটি **Interactions API** (`/v1beta/interactions`) ব্যবহার করে — এটাই গুগলের বর্তমান রেকমেন্ডেড API; কোনো কারণে না চললে `generateContent`-এ ফলব্যাক করে।

**সবচেয়ে শক্তিশালী — OpenRouter (ফ্রি মডেলের ভান্ডার):**
1. [openrouter.ai/keys](https://openrouter.ai/keys) → সাইন ইন → **Create Key**
2. অ্যাপে key পেস্ট → ⟳ চেপে **ফ্রি মডেল** লিস্ট লোড করো
3. যেকোনো `:free` মডেল বেছে নাও (DeepSeek R1, Qwen3 235B, Kimi K2, Llama 3.3 70B…)
4. চাইলে **“ওয়েব সার্চ চালু রাখো”** টিক দাও → লাইভ ইন্টারনেট তথ্য

**আরও অপশন:** Groq ([console.groq.com/keys](https://console.groq.com/keys)) — ফ্রি ও দ্রুততম।

### ধাপ ৩ — হোম স্ক্রিনে ইনস্টল (PWA)
- **Android Chrome:** উপরে ডানদিকে ⋮ → **“Add to Home screen”** / **ইনস্টল**
- **iPhone Safari:** Share ⬆️ → **“Add to Home Screen”**
- অথবা অ্যাপের উপরের ⬇ আইকনে চাপো

এরপর হোম স্ক্রিনে **JARVIS** আইকন দেখাবে — চাপলেই ফুলস্ক্রিন অ্যাপ।

## 🔊 বাংলা ভয়েস না থাকলে

**Android:** `Settings → System → Languages & input → Text-to-speech output` → গিয়ার আইকন → **Bangla (Bangladesh)** ভয়েস/ডেটা ইনস্টল করো → অ্যাপ রিফ্রেশ করো।
তারপর সেটিংস → **Voice** → ভয়েস লিস্ট থেকে বাংলা ভয়েস বেছে নাও, **🔊 টেস্ট করো** চেপে শোনো।

## 🏗 টেকনিক্যাল (ডেভেলপারদের জন্য)

```
index.html            — HUD UI (JARVIS স্টাইল)
css/style.css         — ডার্ক সায়-ফাই থিম
js/config.js          — প্রোভাইডার, মডেল, ব্যক্তিত্ব (persona)
js/store.js           — localStorage (নোট, টাস্ক, রিমাইন্ডার, স্মৃতি, চ্যাট)
js/tools.js           — টুল রেজিস্ট্রি (সময়, হিসাব, আবহাওয়া, সার্চ, রিমাইন্ডার…)
js/ai.js              — ইউনিফাইড API লেয়ার + JSON টুল-কল লুপ
js/speech.js          — SpeechRecognition + SpeechSynthesis + wake word
js/app.js             — মূল নিয়ন্ত্রক (UI, রিমাইন্ডার, ড্রয়ার, PWA)
manifest.webmanifest  — PWA ম্যানিফেস্ট
sw.js                 — সার্ভিস ওয়ার্কার (অফলাইন ক্যাশ)
icons/                — অ্যাপ আইকন (192/512/maskable/apple-touch)
```

**লোকাল রান:**
```bash
python3 -m http.server 3000
# অথবা: npx serve .
```
তারপর `http://localhost:3000` খোলো।

**কোনো বিল্ড স্টেপ নেই** — পিওর HTML/CSS/JS। যেকোনো স্ট্যাটিক হোস্টে (Netlify, Vercel, GitHub Pages, Cloudflare Pages) ফ্রি হোস্ট করা যায়।

### টুল কিভাবে কাজ করে
মডেলকে সিস্টেম প্রম্পটে টুলের তালিকা দেওয়া হয়। দরকার হলে মডেল `{"tool":"get_weather","args":{...}}` আকারে JSON দেয় → `ai.js` সেটা পার্স করে `tools.js` চালায় → ফলাফল আবার মডেলকে দেয় → মডেল সাধারণ বাংলায় উত্তর দেয়। সর্বোচ্চ ৪ ধাপ।
এই পদ্ধতি Gemini/OpenRouter/Groq/Ollama — **সবার সাথেই** কাজ করে (নেটিভ function-calling লাগে না)।

### নতুন টুল যোগ করো
`js/tools.js`-এ এক লাইন:
```js
def('my_tool', 'কী করে', '{"arg":"বর্ণনা"}', async (a) => { return 'ফলাফল'; });
```
ব্যাস — মডেল সাথে সাথে এটা ব্যবহার করতে পারবে।

## 🔒 প্রাইভেসি

- API key, চ্যাট, নোট, টাস্ক — **সব তোমার ডিভাইসেই** (localStorage)।
- কোনো নিজস্ব সার্ভার নেই। শুধু তুমি যে AI প্রোভাইডার বেছে নেবে, তার সাথে কথা হয়।
- মাইক অডিও শুধু ব্রাউজারের Speech Recognition-এ যায় (তোমার ফোন/গুগলের সার্ভিস)।
