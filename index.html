নোট, টাস্ক, রিমাইন্ডার ও চ্যাট — সব তোমার ফোনেই থাকে। সার্ভারে কিছু যায় না।

ফ্রি key কোথায় পাবে?

  • Google Gemini: aistudio.google.com/apikey → গুগল অ্যাকাউন্ট দিয়ে ঢুকে Create API key। বিশ্বাস করো, ২ মিনিটের কাজ — সম্পূর্ণ ফ্রি।
  • OpenRouter: openrouter.ai/keys → সাইন ইন → Create Key। এরপর মডেল লিস্টে :free মডেলগুলো বেছে নাও।
  • Groq: console.groq.com/keys — ফ্রি ও খুব দ্রুত।
  • একেবারে ইন্টারনেট ছাড়া: Custom প্রোভাইডারে http://localhost:11434/v1 দিয়ে Ollama চালাতে পারো।

⚠️ ওয়েব-স্পিচ (STT) চালাতে Chrome/Edge ব্রাউজার ব্যবহার করো — Safari-তে মাইক ইনপুট সীমিত।
